# Git

## コミットメッセージ

- Conventional Commits に従う。
- メッセージは日本語で記述する。
- 4 バイト文字(絵文字等)は使用しない。理由: git ホスティングサービス側の制約による。

## フォーマット

```
<type>: <subject>

<body>
```

- `type` は英語小文字: `feat`/`fix`/`refactor`/`docs`/`test`/`chore`/`build`/`ci` 等。
- `subject` は簡潔に。
- `body` は必要に応じて補足する。

### 例

```
feat: ログイン画面にパスワードリセットリンクを追加

パスワードを忘れたユーザが再設定フローへ遷移できるよう
ログインフォーム下部にリンクを追加した。
```
